# despesas

App das despesas da casa (Bernardo e Susana): adicionar, editar e apagar despesas, painel com gráficos, dívidas e transferências.

- O site é este repositório (GitHub Pages); funciona como app instalável no telemóvel.
- Os dados ficam na folha `Despesas_casa.xlsx` do Google Drive, através de um Apps Script (o código de acesso nunca está aqui).
